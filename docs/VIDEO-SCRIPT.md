# Demo video script — WBD Real Estate Suite (≈ 2 minutes)

Narration is in English for the WordPress.org audience. Shot notes (বাংলায়) tell you what to show on screen.
Record at 1920×1080, browser zoom 100%, hide bookmarks bar. Use a clean site: real property photos, no test pages in the menu.

| Time | On screen (কী দেখাবেন) | Narration |
|---|---|---|
| 0:00–0:08 | Plugins → Add New → "WBD Real Estate" → Install → Activate | "Let's build a complete real estate website in two minutes — free, with no page builder." |
| 0:08–0:30 | Welcome notice → **Run the 2-minute setup wizard**। দেশ বাছুন (Bangladesh/US), brand colour বদলান, Continue | "The setup wizard sets your currency, number format and area unit for your country." |
| 0:30–0:45 | Agency step: নাম, email, phone, **WhatsApp number** লিখুন → Continue | "Add your agency and WhatsApp number. Your agent profile is created automatically." |
| 0:45–0:55 | Pages & demo step: সব tick রেখে **Finish setup** | "One click creates the homepage, search, agents, contact and submission pages." |
| 0:55–1:15 | **View your website** → hero search → Buy/Rent tab → filter → results grid → sort | "Visitors search by location, type, price and rooms. Filters live in shareable URLs." |
| 1:15–1:35 | একটা property খুলুন → gallery → key facts → map (Load map) → sidebar এর **WhatsApp** click (pre-filled message দেখান) | "Every property gets a professional layout. Buyers can message the agent on WhatsApp with the property link already filled in." |
| 1:35–1:45 | Phone view (DevTools device mode) → mobile contact bar | "It's fully responsive, with a sticky contact bar on mobile." |
| 1:45–1:55 | Admin → Real Estate → **Leads** → একটা lead খুলুন → stage বদলান → note যোগ করুন | "Every inquiry lands in the built-in CRM: stages, notes, agent assignment and CSV export." |
| 1:55–2:05 | Overview dashboard | "Track new leads, viewings and your most viewed properties — all data stays on your site." |
| 2:05–2:10 | Logo + "Free on WordPress.org" | "WBD Real Estate Suite. Free on WordPress.org." |
